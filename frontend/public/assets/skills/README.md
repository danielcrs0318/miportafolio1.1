# Technology marks

The SVG files in this directory were downloaded from the [Simple Icons](https://github.com/simple-icons/simple-icons) `develop/icons` directory on 2026-10-06. Their paths use the brand hex colors from the same repository's `data/simple-icons.json`, and their proportions are unchanged. The Docker mark also represents Docker Compose in the technology list; the JSON Web Tokens mark is reused for both JWT entries.

Concepts without a distinct brand mark (for example REST APIs, CORS, and embeddings) use a matching local Lucide icon instead. The React component also falls back to a Lucide icon if an SVG fails to load.
