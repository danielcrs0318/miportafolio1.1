# Certificate issuer marks

Downloaded from official brand resources on 2026-10-05. These are issuer logos,
not certification badges. Original artwork, proportions and colors are preserved.

- `github.svg`: GitHub Invertocat Black, from [GitHub's logo library](https://brand.github.com/foundations/logo), [SVG archive](https://brand.github.com/GitHub_Logos.zip).
- `cisco.svg`: [Cisco Security brand assets](https://brand-assets.security.cisco.com/), [light-background SVG](https://brand-assets.security.cisco.com/cisco-light.svg). Added `viewBox="0 0 40 40"` matching its original canvas so the artwork scales correctly.
- `google-cloud.svg`: [Google Cloud](https://cloud.google.com/), [official full-color wordmark](https://www.gstatic.com/cgc/google-cloud-logo-fullcolor.svg). A wider plate keeps the complete wordmark legible on mobile.

Logos are served locally; a Lucide icon is shown if a logo cannot load.
